## Summary

Replace the non-idiomatic `Slog as slog` import alias with direct Pascal case `Slog` usage across all source, test, and documentation files. Simultaneously bump the Python minimum to 3.10, broaden Rich to `>=12,<15`, and broaden pytest to `>=8,<10` in `pyproject.toml`. No new code, APIs, or data models — purely a rename refactor plus version constraint edits.
